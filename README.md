# Muhammet Canlı's Portfolio

This is a simple, clean portfolio website designed for GitHub Pages.

## Features

- Clean, white design
- Responsive layout
- CV download button
- About section
- Projects showcase

## Files

- `index.html` - Main HTML file
- `css/style.css` - Stylesheet
- `assets/cv.pdf` - Placeholder CV (replace with your own)
- `README.md` - This file

## Customization

1. Replace `assets/cv.pdf` with your actual CV PDF file.
2. Edit `index.html` to update your personal information, bio, and projects.
3. Modify `css/style.css` to adjust colors, fonts, or layout if desired.
4. Push to GitHub and enable GitHub Pages in the repository settings.

## Development

To preview locally, you can open `index.html` in a browser or use a simple static server.

## Deployment

This site is ready for GitHub Pages. Simply push to the `main` branch and enable GitHub Pages in the repository settings under the "Pages" section.
